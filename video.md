## Topics Covered

- File creation, writing, closing, and reopening
- File metadata using `stat()` and `fstat()`
- File descriptors and `struct file`
- Inode structures and metadata
- Direct and indirect block mapping using `bmap()`
- Disk-block allocation using `balloc()` and `bfree()`
- Multi-block file write/read verification
- Data integrity verification
